# 01wanwu v0.1 交付说明（给产品经理）

> 从0到1，搭建万物。研究者把一个研究的所有材料丢进来，我们整理成一个干净的公开页面，链接可以直接放进简历和网申。

## 1. 现在能用的东西

| 部分 | 状态 | 位置 |
|---|---|---|
| MCP Server（13 个工具 + 1 个完整工作流 prompt） | 可用，已端到端测试 | `wanwu/mcp/` |

## 2. 用户流程（agentic workflow）

用户在 Claude（或任何支持 MCP 的 AI 工具）里说一句"帮我把这个研究放到 01wanwu"，AI 按 `showcase_study` prompt 走八步：

1. **建档**：作者（姓名、单位、身份）+ 研究（标题、按顺序的作者列表）。只问找不到的信息，不猜合作者单位。
2. **导入**：文件、整个文件夹、Google Docs/Sheets/Drive 链接。
3. **阅读**：逐个读取解析出的文字，整理一份事实清单（问题、数据、方法、带出处的数字结果、局限、时间线）。
4. **分区**：检查自动分区，给每张图写一句说明。
5. **写页面**：Overview（三段：问题、做了什么、发现与把握程度）、Outcome、Data、Code、References、Log。每个数字都要能追溯到材料。
6. **征得同意**：列出每个文件的公开/私有建议，作者确认。
7. **检查与预览**：`check_study` 清空问题清单，本地预览。
8. **发布**：先给作者看"将公开的内容清单"，作者明确同意后才推送上线。

## 3. 我替你做的决定（都可以改）

| 决定 | 理由 | 改起来难不难 |
|---|---|---|
| **用路径，不用子域名**：`01wanwu.si/yujiazou/wetland-cooling/data/` | Yujia 给的例子就是路径；一个证书、一个部署、SEO 权重集中。子域名（`yujiazou.01wanwu.si`）以后可以用 Vercel 通配域名 + rewrite 映射到同一路径 | 容易 |
| **01wanwu.si 根目录暂时保持原作品集页面不变** | Yujia 简历上已经放了这个链接。平台首页先放在 `/explore/`。上线公开推广时，把根目录换成 Research hub，原链接 301 到 `/yujiazou/wetland-cooling/` | 改一个参数：`--home explore` |
| **固定六个分区**：Overview、Outcome、Data、Code、References、Log | 每个研究页结构一样，导师和面试官一眼就会看。会议、海报、论文都归 Outcome；工作记录和会议录音归 Log。空分区自动隐藏 | 在 `lib/constants.mjs` 加一行即可 |
| **上传的东西默认全部私有** | 兑现"未经允许绝不查看或使用"的承诺。分类器只给建议：原始数据、未发表稿件、会议记录和录音建议私有；图、代码建议公开 | 产品上可以改成"一键接受建议" |
| **私有区和公开区物理分开** | 私有材料只在用户自己的工作区；发布时只复制公开文件到网站仓库，连私有文件的名字都不导出 | 架构决定，建议保留 |
| **作者顺序就是用户给的顺序**，合作者如果也有 01wanwu 账号就自动链接，他们的作者页会出现"Co-authored" | 学术惯例；也是社区效应的起点 | — |
| **页面是英文，站点标语保留中文"从0到1，搭建万物"** | 目标读者是导师、海外招聘官 | 可加中英切换 |
| **纯静态 HTML，无框架** | 快、便宜、Vercel 免费层足够、PM 和设计师改 CSS 就能调样式 | v0.3 有登录后可能需要 Next.js |
| **Star 先存在访客浏览器里** | v0.1 没有账号系统，按钮先占位，交互是真的 | v0.2 换成服务端计数 |
| **每个研究页自带引用格式** | 学术用户最常复制的东西 | — |
| **不展示估值、不夸大** | Yujia 的条目沿用之前审过的口径（例如不写 3.6 万美元估值） | — |

## 4. 还没做、建议的顺序（Roadmap）

**v0.2：让别人能用（多用户）**
- 网页上传入口（拖拽整个文件夹 / 连接 Google Drive），后台跑同一套 MCP 工作流。建议：Supabase（账号 + 存储 + 数据库）或 Vercel Blob + Postgres。
- 账号与 handle 认领；合作者邀请（"Bo Li 邀请你确认作者身份"）。
- 发布不再走 git，改为写数据库 + 增量重建（Vercel ISR 或 on-demand revalidate）。
- 服务端 Star / Like 计数、"我 star 的研究"。

**v0.3：社区（Research hub）**
- 按领域、学校、方法的标签浏览；搜索；"本周新研究"。
- 关注作者、研究更新提醒（Log 有新条目时）。
- 研究版本：每次发布留快照，可以引用某个版本。
- 申请 DOI（Zenodo 集成），让页面本身可被正式引用。

**v0.4：对大牛和机构的吸引力**
- ORCID / Google Scholar 导入已有论文，一键生成多篇研究页。
- 实验室页面（`01wanwu.si/lab/<name>`）汇总成员研究。
- 数据和代码的可复现徽章。
